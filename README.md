## Subconjunto

- Unicode: `U+0000-00FF`, `U+0100-017F`, `U+2000-206F`, `U+20AC`, `U+2122`.
- Sem cirílico, grego ou outros blocos não latinos.
- Grenze: instanciada em `wght=700` a partir da variável oficial.
- Conversão: `fonttools 4.68.0` + `brotli 1.2.1`, usados apenas no ambiente de
  desenvolvimento; nenhuma ferramenta foi incluída no app.
